This is a repository for my python bots that run on my raspberry pi, including programs that allow me to run and update the bots without "ssh-ing" into it.

weebbot.py: this is a music bot that runs on my private discords, it can search for songs and plays them in the server. It can handle youtube and spotify links as well as keep a queue to keep the songs playing.

cleaner_bot.py: this cleans the discord chat of the weebbot messages automatically.

updatePlaylistFile.py: this application allows me to run and recover the bots, as well as update files and dependencies on the raspberry pi.
